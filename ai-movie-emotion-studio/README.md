# AI 电影情绪创作工作台

> 一个面向电影/短剧创作者的 **AI 辅助创作工具**，把"情绪设计"作为核心维度，分镜、台词、节奏一站式生成。

[🔗 体验方式](#本地运行)

---

## ✨ 项目亮点

- 🎬 **以"情绪"为第一性原理**：不像传统剧本工具按"场景"分，而是按"情绪弧"组织内容
- 🤖 **多 prompt 角色协作**：导演 prompt / 编剧 prompt / 情绪分析师 prompt 协同工作
- 🎨 **视觉风格统一**：电影海报风格的紫黑配色 + Bangers 字体致敬经典电影海报
- 📱 **响应式设计**：手机/平板/桌面均可用
- 🌙 **深色模式**：内置深色模式，夜间使用不刺眼
- 💾 **本地存储**：所有创作数据存 localStorage，无后端依赖

---

## 🤖 AI 协作开发流程

### 阶段 1：概念验证（MVP）

**我的需求**：做一个工具，帮我把"想拍什么"快速变成"剧本/分镜"。

**我给 AI 的关键约束**：
- 不要做"通用 AI 聊天工具"，要做**专用工具**
- 工具的核心概念是"情绪"，不是"剧本格式"
- UI 要像电影海报，不要像 SaaS 后台

**AI 第一版**：做了一个标准的"聊天框 + 表单"工具。
**我的反馈**：太普通，没有体现"电影"和"情绪"的视觉感受。
**AI 第二版**：用紫黑配色 + Bangers 字体 + 卡片阴影，致敬经典电影海报。
**我的反馈**：这次感觉对了。

### 阶段 2：多角色 Prompt 设计

**我**的核心想法：
- 单一 AI 角色既当导演又当编剧又当分析师，效果会"四不像"
- 让 AI 在不同环节"切换"角色，效果会更专业

**AI 的实现**：在 prompt 里加 `<role>` 标签，让 AI 在不同标签下用不同人设。
**我的反馈**：标签机制不够清晰，AI 会忘记当前角色。
**最终方案**：每个 prompt 独立成独立按钮触发的"角色卡"，用户点击哪个按钮就调用哪个角色的 prompt 链路。

### 阶段 3：情绪可视化

**我的需求**：让用户能直观看到"情绪弧线"而不是只能看文字。

**AI 的方案**：用 ASCII 字符画情绪曲线。
**我的反馈**：太丑，没有"电影感"。
**最终方案**：用 CSS 实现情绪渐变色块 + 节奏标记，让情绪可视化但不破坏电影海报风格。

### 阶段 4：打磨细节

- 调整字体大小（标题用 Bangers 大字号，正文用 system font）
- 深色模式调色（不能太黑，要保留"电影院"的感觉）
- 输入框 placeholder 改成"电影台词式"的引导语（"这部电影的灵魂是___"）
- 添加"导出剧本"按钮，一键复制 Markdown 格式

## 🚀 本地运行

### 方法 1：浏览器直接打开
双击 `index.html` 即可。

### 方法 2：本地 HTTP 服务
```bash
cd ai-movie-emotion-studio
python3 -m http.server 8001
# 浏览器打开 http://localhost:8001
```

## 🔒 Security / 隐私说明

- API Key 由**用户运行时自行输入**，存于浏览器 `localStorage`，**不上传任何服务器**
- 本仓库**不包含**任何真实 API Key

## 📝 功能模块

- **意图输入**：用户输入想表达的核心情绪/故事
- **情绪分析**：AI 分析情绪类型、强度、节奏
- **分镜建议**：AI 生成镜头建议（景别/运镜/光线）
- **台词生成**：AI 生成符合情绪的台词
- **节奏曲线**：可视化展示情绪起伏
