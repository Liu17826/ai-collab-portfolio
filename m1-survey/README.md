# M1 需求澄清问卷

> 一个**自适应问卷**，根据用户的初始回答自动分支到不同的澄清路径，帮咨询师/教练快速了解客户真实需求。

[🔗 体验方式](#本地运行)

---

## ✨ 项目亮点

- 🌿 **4 路自适应分支**：根据用户对"你清楚目标吗"的回答，自动选择 A/B/C/D 四种澄清路径
- 🌓 **深色模式**：跟随系统主题自动切换
- 📱 **移动端优先**：单页布局，触摸友好
- ✨ **极简代码**：单文件 ~11KB，纯 HTML/CSS/JS
- 💾 **进度本地保存**：刷新不丢

---

## 🛠️ 技术栈

## 🤖 AI 协作开发流程

### 阶段 1：问题设计

**我的需求**：做一个不像"填表"的问卷，让用户感觉是在"被倾听"。

**我给 AI 的关键约束**：
- 问题设计要有"教练式对话"的感觉，不是冷冰冰的"1. 您的职业是？"
- 根据用户回答动态调整后续问题
- UI 要干净、克制，不要花哨

**AI 第一版**：把所有问题列在一个长表单里。
**我的反馈**：太机械，像问卷调查。需要让学生主动用"分支对话"的形式。
**AI 第二版**：4 路分支（A 我清楚/B 我大致方向/C 我不知道/D 我有好几个目标），每路 5 个深度问题。
**我的反馈**：分支对了，但问题措辞还是"问卷腔"，需要"对话腔"。
**最终**：每个问题改成"我想了解..."/"如果...你会怎么想..."的句式。

### 阶段 2：UI 极简化

**我**的 UI 原则：
- 一屏只显示一个问题（不让用户有压迫感）
- 顶部进度条（5 步）让用户有"快做完了"的希望
- 按钮要克制，不要太花哨
- 深色模式要"安静"，不能像普通 App 那么黑

**AI 的实现**：纯色卡片 + 大字号问题 + 单选/多选 chips + 顶部进度条。
**我的反馈**：卡片间距再小一点，标题字号大一点（21px），副标题用 muted 色。
**最终**：极简但有质感的问卷 UI。

### 阶段 3：分支逻辑

**我**的分支规则：
- A（清楚）→ 深挖目标细节（期限/标准/意义）
- B（有方向）→ 把方向变具体（改善哪方面）
- C（不知道）→ 一起探索方向（什么让你不满意）

**AI 的实现**：用对象嵌套存储分支问题树。
**我的反馈**：结构 OK，但切换分支时进度要保留。
**最终**：用 `currentPath` 变量记录当前分支路径，进度按"路径内问题数"计算。

## 📝 4 路分支设计

| 用户状态 | 分支 | 核心问题 |
|---------|------|---------|
| **A** 我很清楚想要什么，只是不知道怎么实现 | 深挖目标 | 你希望具体达到什么结果？ |
| **B** 我有一个大致方向，但还没想清楚 | 把方向变具体 | 你最想改善的是哪一方面？ |
| **C** 我知道对现状不满意，但还不知道想要什么 | 一起探索方向 | 目前最让你满意的是什么？ |
| **D** 我有好几个目标，不知道该优先考虑哪个 | 优先级排序 | 这些目标中，哪一个最重要？|

## 🎓 这个项目教会我的事

1. **问卷/表单设计也是 UX 设计**：措辞、顺序、分支都是体验的一部分
2. **"对话腔"比"问卷腔"更容易被接受**：同样收集信息，用户感觉完全不同
3. **极简 UI 反而需要更多设计决策**：留白、字号、间距都是设计
4. **分支逻辑要可视化设计**：先画流程图再写代码
