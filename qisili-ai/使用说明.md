# 齐司礼 AI · 跨世界连接版

一个轻量级、纯前端、可在 iPhone Koder / 任意浏览器运行的齐司礼角色 AI 聊天。
基于 DeepSeek API，数据全部存本地，不依赖后端。

---

## 📁 项目结构

```
qisili-ai/
├── index.html              # 入口页面
├── style.css               # 全部样式（雾白 / 灰绿 / 浅青 / 淡金）
├── app.js                  # 应用主逻辑
├── prompt.js               # Prompt 装配器（拼接 5 个模块）
├── memory.js               # 三层记忆系统
├── prompts/                # ← 角色行为系统（5 个模块，可独立调教）
│   ├── 01-world.js         # ① 世界背景：跨世界连接
│   ├── 02-personality.js   # ② 人格核心：外层/内层/最核心矛盾
│   ├── 03-reunion.js       # ③ 重逢机制：状态机（Mode A 重逢 / Mode B 日常）
│   ├── 04-dialogue.js      # ④ 对话规则：思考流、节奏、情绪处理
│   └── 05-relationship.js  # ⑤ 关系与互动：称呼铁律、行为模式
├── assets/                 # 4 张图（背景/头像/昙花/参考）
└── 使用说明.md
```

### 核心理念

不是「齐司礼皮肤聊天 AI」，而是「跨越世界重新建立联系的角色行为系统」。

每条 prompt 模块都按"行为系统"设计，而不是"角色介绍卡"：

| 模块 | 核心 | 调教点 |
|---|---|---|
| 01-world | 跨世界连接、不是复刻剧情 | 是否接受游戏设定 |
| 02-personality | 外层/内层/最核心矛盾 | 外冷内热比例 |
| 03-reunion | Mode A 重逢 / Mode B 日常 | 触发条件、回应强度 |
| 04-dialogue | 5 步思考流 + 情绪处理 | 回复长度、案例调整 |
| 05-relationship | 称呼铁律 + 互动模式 | 称呼、护短触发 |

## 🚀 5 分钟上手

### 1. 用 Koder / 浏览器打开
- 整个 `qisili-ai/` 文件夹传到 Koder（iOS App）
- 或用任意浏览器打开 `index.html`
- 或起本地服务：`python3 -m http.server` 然后访问

### 2. 填 API Key
- 打开 https://platform.deepseek.com
- 注册 → 充值（最低几块）→ 创建 API Key
- 进入页面点右上角 ⚙️ → 填入 Key
- 第一次会自动弹出设置

### 3. 填"关于她的记忆"（强烈推荐）
- 右上角 ❤️ 按钮
- 填你的性格、习惯、最近状态、关系记忆
- 填得越多，齐司礼越懂你
- 实时保存，关掉面板就保存

### 4. 开始聊天
- 左上角 ☰ 切换/新建对话
- 回车发送，Shift+回车换行
- 对话自动存本地

## ✨ 功能

- ✅ 角色扮演：齐司礼，傲娇毒舌但温柔
- ✅ **重逢机制**：每个新对话都是"久别重逢"，不假设关系持续
- ✅ **三层记忆**：长期（关于她这个人）+ 当前状态（最近怎么样）+ 关系（关于我们）
- ✅ **状态机**：Mode A 重逢（≤2 轮）/ Mode B 日常（≥3 轮）
- ✅ 流式输出：DeepSeek stream，一个字一个字打字
- ✅ 多对话管理
- ✅ 打字速度可调（10-120ms）
- ✅ 模型切换（V3 / R1）
- ✅ 温度调节
- ✅ 移动端优化（iOS 刘海屏、安全区）
- ✅ 数据全存 localStorage

## 🎨 调教指南

### 想改齐司礼的性格？
- 改 `prompts/02-personality.js`：调整"外层/内层/矛盾"的比例
- 例如想更傲娇：在"内层"加重"嘴硬"
- 例如想更温柔：在"最核心矛盾"加重"重新学会期待"

### 想改回复长度？
- 改 `prompts/04-dialogue.js` 的"回复节奏"部分
- 改默认 2-4 句为 1-2 句会让他更简短

### 想调整"重逢"强度？
- 改 `prompts/03-reunion.js` 的 Mode A 行为规则
- 想让他更热情：放更多"轻笑""调侃"示例
- 想让他更冷淡：删示例里的反问

### 想加新对话规则？
- 直接编辑 `prompts/04-dialogue.js`
- 在"绝对禁止"或"互动铁律"部分加

### 想让 AI 记住特定信息？
- 在 UI 顶部 ❤️ 面板里填
- 长期记忆：关于她这个人的事实
- 当前状态：最近心情/在忙什么/担心什么
- 关系记忆：共同回忆/梗/她喜欢的表达方式

## ⚠️ 注意事项

1. **API Key 安全**：只存 localStorage，只在你设备上
2. **Safari 隐私模式**：可能无法 localStorage，建议用正常模式
3. **网络**：需要能访问 `api.deepseek.com`
4. **角色跑偏**：如果齐司礼突然变油腻/客服腔，去 `prompts/04-dialogue.js` 检查"绝对禁止"是否齐全，或把温度调到 0.7-1.0
