# 语法训练营（Grammar Camp）

> 一个**移动端优先**的英语语法学习 App，纸质笔记本风格 UI，把枯燥的语法规则变成可触摸的卡片和进度点。

[🔗 体验方式](#本地运行)

---

## ✨ 项目亮点

- 📱 **移动端优先的精致 UI**：参考纸质笔记本的视觉语言（米黄底色 + 墨黑文字 + 紫色装饰）
- 🎯 **关卡化学习**：按主题拆关卡（时态/从句/虚拟语气等），进度可视化
- 🎨 **CSS Variables 主题**：根目录定义色彩 token，方便做深色模式或换肤
- ✨ **流畅微交互**：点击反馈、进度条动画、悬停效果均经过打磨
- 📦 **零依赖**：纯 HTML/CSS/JS，无任何外部库

---

## 🛠️ 技术栈

| 类别 | 选型 |
|------|------|
| 前端 | 单文件 HTML + 内联 CSS/JS |
| 样式 | CSS Variables + 响应式布局 |
| 字体 | 系统字体 + Songti SC（衬线字体）|

## 🤖 AI 协作开发流程

### 阶段 1：UI 风格定义

**我的需求**：做一个"不像 App 的 App"，让学习有纸质笔记本的温度。

**我给 AI 的关键约束**：
- 不要用 Material Design / iOS HIG 的标准控件
- 用纸质笔记本的视觉语言（米黄底色 + 墨黑 + 手写感字体）
- 字号偏大、间距宽松，让用户有"翻书"的感觉
- 进度用"小圆点"而不是进度条（更接近翻书的感觉）

**AI 第一版**：标准卡片式 UI，配色偏 SaaS。
**我的反馈**：太现代，没有"笔记本感"。
**AI 第二版**：米黄底色 + 衬线字体 + 圆角卡片。
**我的反馈**：这次对了，但卡片用色太杂，需要更统一的调色板。
**最终**：定义了 12 个核心 CSS Variables（--paper/--ink/--purple/--pink 等），所有 UI 元素严格使用变量。

### 阶段 2：内容结构

**我**的学习内容思路：
- 按主题分关卡（每个语法点一个关卡）
- 每个关卡分多个"知识点卡"
- 每个卡有 1) 规则讲解 2) 示例 3) 练习题

**AI 的实现**：3 个层级数据结构（关卡 → 知识点 → 题目）。
**我的反馈**：数据结构可以，但 AI 默认把所有题都展示出来，没有"渐进式解锁"的体验。
**最终方案**：增加"已完成知识点"记录，已完成的卡显示 ✓，未完成的卡有"未解锁"视觉提示。

### 阶段 3：微交互打磨

**我**的微交互清单：
- 卡片点击时的轻微缩放（`transform: scale(0.97)`）
- 长按时的反馈（按住查看提示）
- 答题正确时的彩纸屑动画
- 切换主题时的过渡动画

每个微交互都是先让 AI 写基础版，然后我指出"还差点意思"的地方，AI 再调一版。比如答题正确时的动画，AI 第一版只是一个 ✓ 图标消失，我让它"加个庆祝感但不要太喧宾夺主"，最终用了淡入的小星星 + 轻震动。

## 🚀 本地运行

### 方法 1：浏览器直接打开
双击 `index.html` 即可。移动端体验更佳。

### 方法 2：本地 HTTP 服务
```bash
cd grammar-camp
python3 -m http.server 8002
# 浏览器打开 http://localhost:8002
```

### 方法 3：手机访问
把 `index.html` 上传到任意静态网站托管（Vercel / Netlify / GitHub Pages），手机扫码即可使用。

## 🎓 这个项目教会我的事

1. **设计语言要提前定义**：CSS Variables 是设计 token 化的最佳实践
2. **"不像 App 的 App"反而更有记忆点**：UI 同质化严重时，反主流设计更容易被记住
3. **微交互是体验的关键**：一个 0.1 秒的缩放反馈，比 10 个功能都重要
4. **约束比自由更有效**：给 AI 明确的"不要做什么"比"要做什么"产出更稳定
