# 中译英翻译训练营（Translation Camp）

> 一个**移动端优先**的中译英训练 App，用户输入中文句子 → 自己翻译成英文 → AI 逐句批改。

[🔗 体验方式](#本地运行)

---

## ✨ 项目亮点

- 🎯 **结构化翻译法训练流程**：想词伙 → 想句式 → 翻译 → 对照参考 → AI 批改
- 🤖 **AI 逐句批改**：用 DeepSeek / 智谱 / 通义千问 等国内大模型，自动找出语法错误
- 📚 **题库覆盖**：教育 / 历史 / 经济 / 文化等主题，按难度分级
- 📱 **移动端优先**：iPhone / Android 触屏体验优化
- 📊 **进度统计**：关卡化展示，错误回顾，错题本自动归档
- 🎨 **纸质笔记本风格 UI**：米黄底色 + 墨黑文字 + 紫色装饰

## 🤖 AI 协作开发流程

### 阶段 1：概念设计

**我**的核心需求：做一个像纸质笔记本一样有温度的语言学习工具，不要"App 腔"。

**给 AI 的关键约束**：
- UI 参考纸质笔记本的视觉语言（米黄底色 + 衬线字体）
- 移动端优先
- 学习流程要"少即是多"（不要堆砌功能）

**AI 第一版**：标准 SaaS 风的卡片列表 UI。
**我的反馈**：太工具化，缺少学习温度。
**AI 第二版**：用 CSS Variables 实现米黄底 + 衬线标题 + 圆角卡片。
**最终**：定义了 13 个核心色彩变量，所有元素严格使用变量，便于后续主题切换。

### 阶段 2：AI 批改逻辑

**我的核心要求**：
- 批改要**温和但严谨**（不要一味夸赞，要找出真问题）
- 输出格式要**结构化**（不是一段话，是分点）
- 不能打击用户信心（鼓励 + 改进建议并存）

**AI 的实现**：用 prompt 约束输出 JSON 格式 `{grade, errors, suggestions, improved}`。
**我的反馈**：JSON 太机器感，用户读起来累。
**最终**：输出 Markdown 格式（标题 + 列表），既结构化又可读。

### 阶段 3：题库数据

**我**的策略：
- 题目按主题分（教育/经济/文化/历史）
- 每个主题 5-10 道题，从易到难
- 每道题包含：中文原文 + 参考译文 + 难度标签

**关键决策**——**用 AI 生成题目而不是手动写**：让 AI 根据主题自动生成 100+ 题目，人工挑选质量高的。

### 阶段 4：错误回顾与错题本

**我的需求**：用户做完题后能"复习错题"。
**AI 的实现**：自动收集打错/低分的题目到错题本。
**我的反馈**：加一个"错题深度分析"功能——AI 汇总错题模式（语法点、词伙薄弱）。
**最终**：增加"错题报告"页面，AI 分析用户的薄弱点。

## 🚀 本地运行

### 方法 1：浏览器直接打开
双击 `index.html` 即可。移动端体验更佳。

### 方法 2：本地 HTTP 服务
```bash
cd translation-camp
python3 -m http.server 8004
# 浏览器打开 http://localhost:8004
```

### 方法 3：手机访问
把 `index.html` 上传到任意静态网站托管（Vercel / Netlify / GitHub Pages），手机扫码即可使用。

## 📝 使用流程

1. **配置 API Key**：右上角"AI 设置" → 填入 DeepSeek / 智谱 / 通义千问 等任一家的 API Key
3. **选关卡**：从首页选择一个主题
4. **翻译练习**：输入中文 → 自己写英文翻译 → AI 批改
5. **错题回顾**：做完一组后进入"错题本"复习

---

## 🔒 Security / 隐私说明

- API Key 由**用户运行时自行输入**，存于浏览器 `localStorage`，**不上传任何服务器**
- 本仓库**不包含**任何真实 API Key
- 所有翻译数据、错题记录仅存在用户本地浏览器

> ⚠️ **架构说明**：本项目聚焦于**前端 AI 集成**的能力展示。For production deployment, API requests should be routed through a backend service to protect credentials.

## 🎓 这个项目教会我的事

1. **AI 批改 prompt 要"温和但严谨"**：鼓励式反馈比纯纠错更有效
2. **题库可以用 AI 批量生成 + 人工筛选**：效率比纯手写高 10 倍
3. **错题本是核心留存点**：用户做完题后的"复习需求"是真正的粘性来源
4. **纸质笔记本的视觉风格在移动端具有差异化**：UI 同质化严重时，反主流设计反而更有记忆点
